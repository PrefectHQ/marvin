A `Thread` stores messages and model-call usage in Marvin's database. The default database is `~/.marvin/marvin.db`; history survives process restarts as long as the database is retained.

```python
import marvin

with marvin.Thread() as thread:
    marvin.say("My name is Ada.")
    name = marvin.run("What is my name?", result_type=str)

print(thread.id)
```

The context manager selects the current thread. Leaving it does not delete history.

## Resume a conversation

Save the thread ID and use it for later calls against the same database:

```python
import marvin

thread = marvin.Thread(id="support-example")
marvin.say("My order number is 12345.", thread=thread)
order_number = marvin.run(
    "What is my order number?",
    result_type=int,
    thread="support-example",
)
```

Without an explicit or current thread, a call creates a new one.

## Inspect history and usage

```python
import marvin

thread = marvin.Thread(id="support-example")
messages = thread.get_messages()
usage = thread.get_usage()
```

Use `get_messages_async` and `get_usage_async` in async code. Database configuration is described in [configuration](/guides/configuration).

Threads keep conversation history. [Memory](/concepts/memory) stores facts that agents can retrieve by semantic search; its persistence depends on the provider.
