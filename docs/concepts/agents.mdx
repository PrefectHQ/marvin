An `Agent` groups a model, instructions, tools, and optional memory. Calling `agent.run` creates and runs a task with that agent.

```python
import marvin

editor = marvin.Agent(
    name="Editor",
    instructions="Edit for clarity. Preserve the author's meaning.",
)
revision = editor.run(
    "Edit the supplied sentence",
    context={"sentence": "We are in receipt of your message."},
)
```

## Assign an agent to a task

```python
import marvin

editor = marvin.Agent(name="Editor", instructions="Write concise prose.")
task = marvin.Task(
    "Rewrite the supplied sentence",
    agents=[editor],
    context={"sentence": "We are in receipt of your message."},
)
revision = task.run()
```

Use `agents=[editor]` with `marvin.run` or `Task`, and `agent=editor` with helpers such as `cast` and `extract`.

## Models and tools

Set `model="provider:model-name"` or pass a Pydantic AI model instance. Pass ordinary Python functions in `tools=[...]`. See [model configuration](/guides/configure-llms) and [tools and context](/concepts/tools-and-context).

An agent does not store conversation history itself. Reuse a [thread](/concepts/threads) to retain messages across calls, or attach [memory](/concepts/memory) for searchable facts.

For multiple agents, coordinate their calls explicitly in Python. The [team classes are deprecated](/concepts/teams).
