title: Teams (deprecated)
description: Replace team orchestration with explicit agent calls
icon: users
---

All team classes, including `Team`, `Swarm`, `RoundRobinTeam`, and `RandomTeam`, are deprecated. They have incomplete coordination behavior and remain available for compatibility.

Coordinate agents explicitly instead:

```python
import marvin

writer = marvin.Agent(name="Writer", instructions="Write concise prose.")
editor = marvin.Agent(name="Editor", instructions="Edit for clarity.")

with marvin.Thread():
    draft = writer.run("Explain Python type hints in one paragraph")
    revision = editor.run("Edit the draft", context={"draft": draft})
```

For dependency-based execution, assign one agent to each [task](/concepts/tasks) and connect tasks with `depends_on`.
