Marvin requires Python 3.10 or later.

<CodeGroup>
```bash uv
uv add marvin
```
```bash pip
python -m pip install marvin
```
</CodeGroup>

Export credentials for your provider before running a model request. OpenAI is the default:

```bash
export OPENAI_API_KEY="your-api-key"
```

See [model configuration](/guides/configure-llms) for other providers. Vector-memory providers have separate dependencies; see [memory](/concepts/memory).

## Development

```bash
git clone https://github.com/PrefectHQ/marvin.git
cd marvin
uv sync
uv run pytest tests/basic
```

Development dependencies are a dependency group, not a `dev` package extra. The Slack bot has its own workspace package under `examples/slackbot`.

Continue with the [quickstart](/quickstart).
