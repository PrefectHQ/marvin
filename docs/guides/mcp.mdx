---
title: Using MCP Servers
description: Expose MCP tools to a Marvin agent
---

Pass an MCP connection through `Agent(mcp_servers=[...])`. Pydantic AI provides the client integration through `MCPToolset`.

## HTTP servers

Use `MCPToolset` for an HTTP MCP server:

```python
import marvin
from pydantic_ai.mcp import MCPToolset

server = MCPToolset("http://localhost:8000/mcp")
agent = marvin.Agent(mcp_servers=[server])
answer = agent.run("List the tools you can use")
```

The server must already be running.

## Subprocess servers

Pass a FastMCP `StdioTransport` to `MCPToolset` to start a server as a subprocess:

```python
import marvin
from fastmcp.client.transports import StdioTransport
from pydantic_ai.mcp import MCPToolset

git = MCPToolset(StdioTransport(command="uvx", args=["mcp-server-git"]))
agent = marvin.Agent(mcp_servers=[git])
```

The subprocess receives `PATH`, `HOME`, and the variables in `env`. See [Pydantic AI's MCP client documentation](https://ai.pydantic.dev/mcp/client/).

## In-process FastMCP

Install the optional server package:

```bash
uv add "marvin[mcp]"
```

```python
import marvin
from fastmcp import FastMCP

server = FastMCP("calculator")

@server.tool
async def add(a: int, b: int) -> int:
    return a + b

agent = marvin.Agent(mcp_servers=[server])
answer = agent.run("Use add to calculate 23 + 19", result_type=int)
```

A `Thread` context keeps managed server connections available across calls and closes them on exit. See [threads](/concepts/threads).
