---
title: Tools
description: Write a typed Python function for an agent to call
---

A tool is an ordinary Python function. Its signature and docstring describe the arguments and purpose to the model.

```python
import marvin

async def stock_level(product: str) -> int:
    """Return units in stock for a product."""
    return {"notebook": 12, "pen": 30}[product]

agent = marvin.Agent(tools=[stock_level])
count = agent.run("Check notebook stock with stock_level", result_type=int)
```

Sync and async tools are supported. Exceptions are converted to retry feedback so the model can try again; use errors that explain what input was invalid.

See [tools and context](/concepts/tools-and-context) for task-level tools and supplied data, or [MCP](/guides/mcp) for external tool servers.
