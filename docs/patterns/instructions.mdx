---
title: Instructions
description: Apply temporary guidance while running tasks
---

`marvin.instructions` adds guidance for calls made inside its context. Nested contexts combine their instructions.

```python
import marvin

with marvin.instructions("Use short sentences."):
    with marvin.instructions("Address Python developers."):
        explanation = marvin.run("Explain type hints in one paragraph")
```

The guidance is removed when the context exits. Task instructions still describe the objective; agent instructions hold reusable behavior.
