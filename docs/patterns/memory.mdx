See [Memory](/concepts/memory) for providers, persistence, direct operations, and attaching memory to an agent.

Use a [thread](/concepts/threads) when the model needs the preceding conversation. Use memory when it needs to search selected facts across conversations. The default memory provider is ephemeral; choose a persistent provider when those facts must survive a restart.
