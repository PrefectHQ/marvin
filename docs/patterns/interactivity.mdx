---
title: Interactivity
description: Let a task ask questions through a local terminal
---

`cli=True` exposes terminal interaction tools to a task. It is intended for local use where a person can answer prompts.

```python
import marvin

name = marvin.run("Ask the user for their name", cli=True)
```

Set `cli` on the task or the `run` call, not on `Agent`:

```python
import marvin
from pydantic import BaseModel

class Preferences(BaseModel):
    name: str
    interests: list[str]

interviewer = marvin.Agent(instructions="Ask one question at a time.")
preferences = marvin.run(
    "Ask for the user's name and interests",
    agents=[interviewer],
    result_type=Preferences,
    cli=True,
)
```

For an application with its own input loop, use [say](/functions/say) and a [thread](/concepts/threads) instead.
