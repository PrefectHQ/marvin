---
title: Plan
description: Ask a model to propose tasks for a goal
icon: list-check
---

`plan` asks a model to create a list of `Task` objects. Planning does not execute those tasks.

```python
import marvin

tasks = marvin.plan("Outline and draft a short introduction to Python type hints")
for task in tasks:
    print(task.instructions)
```

Review the generated instructions, dependencies, assigned agents, and tools before executing the plan:

Run the reviewed list with `marvin.run_tasks(tasks)`.

Use `available_agents` to supply agents that can be assigned to generated tasks, and `tools` to supply available functions. Use explicit Python steps or [task dependencies](/concepts/tasks#dependencies) when the workflow is already known.

`plan_async` is the async counterpart. See [the API reference](/api-reference/marvin-fns-plan) for signatures.
