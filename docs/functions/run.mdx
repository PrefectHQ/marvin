---
title: Run
description: Run a task and return its validated result
icon: play
---

`run` creates a task, runs it, and returns its result. The default result type is `str`.

```python
import marvin
from pydantic import BaseModel

class Contact(BaseModel):
    name: str
    email: str

contact = marvin.run(
    "Extract the contact",
    result_type=Contact,
    context={"text": "Email Ada at ada@example.com"},
)
```

Use `agents=[agent]` to choose an agent, `tools=[function]` to expose tools, and `thread=thread` to select conversation history. Other task options are forwarded to `Task`.

## Run existing tasks

```python
import marvin

outline = marvin.Task("Outline a short guide to Python type hints")
draft = marvin.Task("Write the guide from the outline", depends_on=[outline])
tasks = marvin.run_tasks([outline, draft])
print(draft.result)
```

`run_tasks` returns the task objects. Read each task's `result` and state after execution.

In async code, use `await marvin.run_async(...)` or `await marvin.run_tasks_async(...)`. See [running tasks](/patterns/running-tasks) for failures and [the API reference](/api-reference/marvin-fns-run) for signatures.
