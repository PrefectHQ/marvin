---
title: Say
description: Add a user message and ask an agent to respond
icon: message
---

`say` adds a user message to a thread, then runs a task that responds to it. It returns the response as a string.

```python
import marvin

with marvin.Thread():
    marvin.say("My name is Ada.")
    response = marvin.say("What is my name?")
print(response)
```

You can pass an agent and thread explicitly:

```python
import marvin

assistant = marvin.Agent(instructions="Answer briefly.")
response = marvin.say(
    "Explain Python type hints",
    agent=assistant,
    thread="type-hints-conversation",
)
```

Use `run` when you want task instructions or a typed result rather than a conversational reply. Use `say_async` in async code. See [threads](/concepts/threads) and [the API reference](/api-reference/marvin-fns-say).
