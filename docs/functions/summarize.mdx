---
title: Summarize
description: Summarize supplied content
icon: compress
---

`summarize` asks a model to summarize the data you provide. It returns a string.

```python
import marvin

summary = marvin.summarize(
    "The release fixes fresh installation and preserves token counts in saved history.",
    instructions="Use one sentence.",
)
```

Use `instructions` to specify length, audience, or information to retain. If you need a structured result, use `run` with a `result_type` instead.

`summarize_async` is the async counterpart. Both accept an `agent`, `thread`, and additional `context`; see [the API reference](/api-reference/marvin-fns-summarize).
