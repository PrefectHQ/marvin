---
title: Cast
description: Interpret input as one Python value
icon: right-to-bracket
---

`cast(data, target)` asks the model to interpret input as a value of the target type.

```python
import marvin

amount = marvin.cast("three dollars and fifty cents", float)
```

For structured results, pass a Pydantic model or dataclass:

```python
import marvin
from pydantic import BaseModel

class Address(BaseModel):
    street: str
    city: str
    country: str

address = marvin.cast("123 Main St in New York, USA", Address)
```

Use `instructions` to disambiguate the conversion. Use `extract` when the input can contain multiple matching values.

```python
import marvin

amount = marvin.cast(
    "The ticket was twenty pounds",
    float,
    instructions="Return the numeric amount without currency conversion.",
)
```

`cast_async` is the async counterpart. Both accept `agent`, `thread`, and `context`; see [the API reference](/api-reference/marvin-fns-cast).
