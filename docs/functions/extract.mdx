---
title: Extract
description: Find values in unstructured input
icon: magnifying-glass
---

`extract(data, target)` returns a list of values of the target type.

```python
import marvin

emails = marvin.extract(
    "Contact support@example.com or sales@example.com",
    str,
    instructions="Extract email addresses.",
)
```

For structured values, use a dataclass or Pydantic model:

```python
from dataclasses import dataclass
import marvin

@dataclass
class Contact:
    name: str
    email: str
    phone: str | None = None

contacts = marvin.extract(
    "Ada: ada@example.com. Grace: grace@example.com, 555-0123.",
    Contact,
)
```

`instructions` describes what to find and how to interpret it. It is required when the target is `str`; a type such as `Contact` already supplies a schema.

Use `cast` for a single interpreted value. `extract_async` is the async counterpart. See [the API reference](/api-reference/marvin-fns-extract) for optional arguments.
