Marvin uses language models to turn unstructured input into Python values and to run tasks with tools. [Pydantic AI](https://ai.pydantic.dev/) handles model access and validates outputs.

```python
import marvin

amount = marvin.cast("three dollars and fifty cents", float)
labels = marvin.classify("The service was excellent", ["positive", "negative"])
```

Start with a function when you need one result. Use an [agent](/concepts/agents) to reuse instructions and tools, a [task](/concepts/tasks) to track an objective, and a [thread](/concepts/threads) to share conversation history.

Model outputs vary. Validating a result's type does not establish that its content is correct.

[Install Marvin](/installation), follow the [quickstart](/quickstart), or browse the [examples](https://github.com/PrefectHQ/marvin/tree/main/examples).
